# 🎬 Netflix Content Analysis

A beginner-friendly data analysis project exploring Netflix's content library using Python.

## 📌 About
This project performs Exploratory Data Analysis (EDA) on a Netflix dataset of 8,807 titles to find interesting patterns in genres, countries, ratings, and trends.

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Files
- `Netflix_Analysis.ipynb` — Main analysis notebook
- `netflix_titles.csv` — Dataset

## ▶️ How to Run

1. Clone the repo
```bash
   git clone https://github.com/your-username/netflix-analysis.git
```
2. Install libraries
```bash
   pip install pandas matplotlib seaborn jupyter
```
3. Download the dataset from [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows) and place it in the folder
4. Open the notebook
```bash
   jupyter notebook Netflix_Analysis.ipynb
```

## 📊 What I Analyzed
- Movies vs TV Shows split
- Top genres and countries
- Most popular content ratings
- Yearly and monthly content trends

## 💡 Key Findings
- Netflix has 3x more Movies than TV Shows
- USA, India, and UK produce the most content
- Content additions peaked in 2019
- TV-MA is the most common rating
